# 改编与审稿参考

根据用户的原文、受众和创作要求选择重点。题材仅作启发，不是必须包含的套路：

- 悬疑：明确观众知道什么、人物知道什么，检查线索能否在画面中被发现。
- 都市：把身份、利益和关系压力落到可见选择上，避免只用解释性对白。
- 幻想：先交代影响当前行动的规则，核对能力与代价在场次之间一致。
- 关系戏：让人物目标产生摩擦，以行动和回应呈现关系变化。

## 审核已有剧本

1. 按场次对照原文检查人物称谓、关键事实、时间、因果和道具；区分合理的创作补充与无法核实的事实。
2. 检查人物目标、阻力和本场局面变化是否清楚，结尾是否从已有冲突自然引出下一步。
3. 检查动作和对白顺序是否清晰、场景与道具是否可拍；缺少条件时列为待确认，而不是自行断定。
4. 按场次列出最影响理解或拍摄的问题，说明原文或剧本依据，给出可执行的修改建议；用户要求修改时再输出修改稿。
5. 用户需要镜头建议时，简述景别、运动与叙事目的；没有给定平台或制作要求时，不假称通用的官方标准。

审稿属于创作辅助，不保证平台审核、传播效果或收益。
